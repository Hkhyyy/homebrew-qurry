# Homebrew tap for Qurry

[Qurry](https://github.com/Hkhyyy/qurry) — a free DataGrip alternative for PostgreSQL, MySQL/MariaDB and Redis.

```bash
brew install hkhyyy/qurry/qurry
```

Installs `qurry-tui` (terminal UI) and `qurry-mcp` (MCP server) on macOS (Apple Silicon, Intel) and Linux x86_64.
Update with `brew upgrade qurry`.

The formula is updated automatically by Qurry's release workflow.
